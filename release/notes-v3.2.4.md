# junimo-mcp v3.2.4

## 修了什么

**`sleep` 会谎报写盘。** 这是最要命的一类 bug —— 工具说「进度已写盘」，玩家就敢关游戏，
结果当天全丢。

实测（2026-11-04，JunimoBridge 0.1.1）：

```
游戏内 14:40 → sleep
  回执：睡醒了：秋 24 日（第 1 年）…进度已写盘。
  实际：SaveGameInfo mtime 没变；关游戏重开读回来还是 秋 23 日 06:00 / 21690g
游戏内 06:00 → sleep
  回执：一样说「进度已写盘」
  实际：mtime 更新 ✅ 真写了
```

也就是：**白天强行触发睡觉时，游戏把日期推进了但跳过了存盘**，而原实现只轮询
「day 变了」就当作已落盘。

## 现在怎么判断

1. 睡之前记下 `<APPDATA>/StardewValley/Saves/*/SaveGameInfo` 里**最新的 mtime**
2. 翻日之后轮询最多 20 秒，等这个 mtime 真的前进
3. 三种回执：
   - 变了 → `进度已写盘（已核对存档文件时间）`
   - 没变 → **报错**：`已翻日到 X 日，但存档文件 20 秒内没有更新 —— 进度很可能没落盘…建议再睡一觉`
   - 取不到存档目录 → 如实说明「已翻日；未能核对是否写盘」

## 升级

覆盖 `junimo-mcp.exe` 即可，无配置变化。dsh-junimo 插件用户由插件 0.3.2 自带。
